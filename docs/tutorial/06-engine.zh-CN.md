# 引擎

[English](06-engine.md) | [简体中文](06-engine.zh-CN.md)

## 功能

引擎菜单是运行中监听的按端口视图：一级条目"引擎"（小标签"端口"），其子菜单为各监听端口，每个
端口按固定顺序列出它所提供的功能及编辑各项功能的页面。本模块没有自己的页面——每个条目都是指向
其他模块页面的链接。

数据来自各编辑页面共用的配置草稿，加上 `GET /api/status` 报告的运行中地址与自动 HTTPS 生成的
监听；配置变化或刷新时菜单重建，不丢失当前页面。每个端口和每个列出路由的条目都有"问 AI"按钮，
以技能 `diagnose` 诊断它。见[助手](14-assistant.zh-CN.md)。

## 页面与操作

### 引擎（`#/engine`）

**端口**：按配置书写的顺序；未写监听且自动 HTTPS 开启时，是它生成的 `https` 与 `http` 端口；
一个端口也没有时，只有一个指向监听表单的链接。端口行显示名称与短地址（`127.0.0.1:8080` 记为
`:8080`），完整地址、内核实际绑定的地址（与写入的不同时）和读取失败的提示放在条目的 title 中。

端口名称下的一行小标签是它的协议与没有独立页面的功能：协议（HTTP/1.1、h2c、HTTP/2、TCP、UDP、
SOCKS）、PROXY 协议、HTTP/3、按需证书、客户端证书、自动 HTTPS、MPTCP、点播。

**每个端口的条目**（按固定顺序，只显示端口真正具有的功能）：

1. 路由的处理器：静态文件、直接应答、FastCGI、媒体令牌、媒体页面，然后是按模块 ID 列出的其他处理器；
2. 反向代理路由与正向代理路由；
3. 缓存区与缓存的路由（有路由使用 `cache` 中间件时）；
4. 其他中间件（归为一组，title 列出其模块）；
5. 流媒体配置、各流媒体处理器的路由（HLS、HTTP-FLV、WHIP 推流、WHEP 播放）、点播路由、其输出所播放的频道；
6. WebRTC 配置与各处理器的路由（WHIP、WHEP、WebRTC 代理）；
7. 四层服务、SOCKS 正向代理（其规则在[监听](05-listeners.zh-CN.md)页编辑）、TLS 证书、ACME 证书、自动 HTTPS 与到它的重定向；
8. 最后是监听表单的链接。

列出路由的条目带数量；点击后打开按该处理器筛选的路由页面。
