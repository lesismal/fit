# 概览

[English](04-overview.md) | [简体中文](04-overview.zh-CN.md)

## 功能

概览是菜单的第一个模块，是运行中状态的只读页面，URL 为 `#/gw.overview/overview`。数据来自 Admin API
的 GET 接口（`/status`、`/config/effective`、`/versions`）：fit 现在跑的是什么、每一部分来自哪里、哪里
一直在出错。多数部分链接到编辑它的页面。本页不编辑任何配置。

它每 5 秒刷新一次；顶栏的**自动刷新**复选框可关闭它，**刷新**按钮再读一次，并显示 `更新于 <时间>`。
每次访问只比较本次访问中的刷新。

## 页面与操作

### 概览（`#/gw.overview/overview`）

**六个统计块**：

| 块 | 显示 |
| --- | --- |
| 配置版本 | 运行中配置的版本号、其来源，以及多久之前应用 |
| 重载 | 成功的重载数；旁边是 `{n} 次失败`，有失败时标黄 |
| 当前连接 | 打开的连接数；旁边是 `{n} 个被拒绝` |
| 路由 | 路由数；旁边是 `{n} 个四层服务` |
| 可用后端 | 所有上游后端合计的 `{up} / {all} 可用`，以及上游数；有不可用时标黄 |
| 证书 | 证书数；其中 14 天内到期的数量，有则标黄 |

**卡片**：

- **监听**（带**编辑**）：名称、地址、协议。
- **配置来源**：每个来源一行，按优先级顺序——来源，以及它贡献的监听、路由、上游与四层服务数。
- **被遮蔽**，只在 provider 提供的元素被配置排除时出现：其来源、元素在 provider 提供内容中的路径、
  名称，以及保留了它的来源。
- **上游健康状态**（带筛选框与**编辑**）：每个上游一块——名称、`{up} / {all} 可用`、在途请求数、负载
  均衡策略与来源，有后端不可用时带**问 AI**按钮；其下是每个后端的地址、状态（可用、不可用（健康检查）、
  不可用（失败过多））、在途、成功、失败。
- **路由**（带筛选框与**编辑**）：名称与优先级、监听、匹配、中间件、处理器（及其上游）、来源。
- **四层服务**（带**编辑**）：名称、监听、上游、服务器名、PROXY 协议、来源。
- **证书**（带**证书**）：与 [TLS](18-tls.zh-CN.md) 页相同的证书表——监听、域名、签发者、生效与过期
  时间、序列号，以及剩余天数或已过期。
- **最近版本**（带**全部版本**）：最后 5 个版本，最新的在前，每个有版本号（运行中的带标记）、应用时间与
  来源。

**突增**：两次刷新之间增加的错误计数——上游的失败请求、被拒绝的连接、失败的重载——显示为警告行，写明在
多少秒内增加了多少，并保留一分钟。每一行，以及有后端不可用的上游，都有**问 AI**按钮，以技能 `diagnose`
诊断它；对上游来说，代理到它的路由名称就是技能的输入 `route`。见[助手](14-assistant.zh-CN.md)。
