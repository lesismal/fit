# 概览

[English](04-overview.md) | [简体中文](04-overview.zh-CN.md)

## 功能

概览是运行中状态的只读页面，数据来自 Admin API 的 GET 接口（`/status`、`/config/effective`、
`/versions`）。它每 5 秒自动刷新（顶栏可关闭自动刷新，也可手动刷新），并链接到编辑各部分的页面。
本页不编辑任何配置。

## 页面与操作

### 概览（`#/gw.overview/overview`）

**六个统计块**：

| 块 | 显示 |
| --- | --- |
| 配置版本 | 运行中配置的版本号，其来源与"多久前应用" |
| 重载 | 成功的重载数，失败数（有失败时标黄） |
| 当前连接 | 打开的连接数，被拒绝的连接数 |
| 路由 | 路由数，四层服务数 |
| 可用后端 | 可用 / 全部后端，上游数（有不可用时标黄） |
| 证书 | 证书数，其中 14 天内到期的数量（有则标黄） |

**卡片**（每张都有跳到编辑页的链接）：

- **监听**：名称、地址、协议。
- **配置来源**：每个来源（文件、provider）贡献的监听、路由、上游、四层服务数，按优先级顺序。
- **被遮蔽**：provider 提供、但因名称已被更靠前的来源占用而未采用的元素。
- **上游健康状态**：每个上游一块——名称、可用 / 全部后端、在途请求、负载均衡策略、来源；其下是
  每个后端的地址、状态（可用 / 不可用（健康检查）/ 不可用（失败过多））、在途、成功、失败。
- **路由**：名称与优先级、监听、匹配、中间件、处理器（及其上游）、来源。
- **四层服务**：名称、监听、上游、服务器名、PROXY 协议、来源。
- **证书**：与 [TLS](18-tls.zh-CN.md) 页相同的证书表。
- **最近版本**：最后 5 个版本，跳到[版本](09-versions.zh-CN.md)页看全部。

路由与上游卡片各有筛选框；"编辑"按钮跳到[反向代理](15-reverse-proxy.zh-CN.md)与[四层代理](17-l4-proxy.zh-CN.md)的页面。

**突增**：两次刷新之间增加的错误计数——上游的失败请求、被拒绝的连接、失败的重载——显示为警告行，
保留一分钟。有后端不可用的上游和每次突增都有"问 AI"按钮，以技能 `diagnose` 诊断它。见[助手](14-assistant.zh-CN.md)。
