# 025：在 fit 中实现基于 ICE、STUN 和 TURN 的点对点连接

[English](025-p2p.md) | [简体中文](025-p2p.zh-CN.md)

状态：已接受（2026-11-01）。

## 背景

fit 要连接两台都在 NAT 后面的主机：一台上的服务能被另一台直接访问，经由在两端 NAT 上打出的洞；打不出洞时
（两端都是对称 NAT，或 UDP 被封）经由中继。TCP 和 UDP 服务都要承载。对端要能与其他实现互通：地址发现、连通性检查和中继
遵循 ICE（RFC 8445）、STUN（RFC 8489）和 TURN（RFC 8656），所以 fit 的对端可以使用公共 STUN 服务器或 coturn 中继，
fit 自己的 STUN 和 TURN 服务器也能为其他实现服务。

## 决定

- **协议由 fit 自己在 fib 上实现，不引入新依赖。** 现有的 Go 实现（pion 的 `ice`、`stun` 和 `turn`）在自己的 goroutine
  上读 socket，阻塞在 `ReadFrom` 里，定时器也跑在 goroutine 上；fit 的规则 1 要求所有 socket 都在 fib 的事件循环上，
  一个进程里有两套网络栈也会让要维护的限制和指标翻倍。这些协议本身不大：STUN 是一种分帧加几个属性，TURN 是一张
  allocation、permission 和 channel 的表，ICE 是由定时器驱动的检查表。
- **包结构。** `p2p/stun`（消息、STUN 服务端和客户端）、`p2p/turn`（服务端和客户端）、`p2p/ice`（agent）和 `p2p`
  （连通的候选对上的隧道、信令和配置里的应用）。每一层建立在前一层之上，也可以单独使用。
- **每个 agent 一个 socket，按首字节分流**，与 RFC 7983 和 RFC 9443 相同：0-3 是 STUN，64-79 是 TURN ChannelData 且只来自
  TURN 服务器的地址，其余是 QUIC。NAT 的映射属于本地端口，所以检查、中继流量和负载必须共用它。
- **负载是跑在选中的候选对上的 QUIC**，使用 fib 的 `quic` 包，它已经能跑在调用方给出的任何路径上（`quic.Dial(pc
  PacketConn, ...)`、`Conn.HandlePathDatagram`）。TLS 1.3 用随候选一起交换的证书指纹认证对端，如同 SDP 的 `a=fingerprint`
  之于 DTLS。一条 TCP 连接是一个双向 stream；一个 UDP 流是带 varint 流 ID 前缀的 QUIC DATAGRAM 帧（RFC 9221），与 RFC
  9298 的 context ID 做法相同。QUIC 提供拥塞控制、丢包恢复和路径迁移，这些是裸打洞路径没有的。
- **中继用 TURN。** 汇合点的 fit 运行 TURN 服务器；ICE 收集中继候选，在没有直连候选对成功时退回到它们，同时继续检查直连
  的候选对。TURN 的长期凭据和 coturn `use-auth-secret` 的限时凭据（TURN REST API 草案）都接受。
- **ICE 把信令留给应用；fit 的信令是汇合点 fit 上的一个端点**，交换双方的 ICE 凭据、证书指纹和候选（采用 RFC 8839 的
  `candidate` 语法）。具体形态在 I92 决定。
- **一切都有上限**（规则 11）：STUN 消息（UDP 上 1280 字节，TCP 上 4 KiB）、一条消息的属性数、TURN 的 allocation 总数和
  每用户数、每个 allocation 的 permission 和 channel、每秒中继字节数、ICE 候选数和候选对数（RFC 8445 的 100），每个事务
  都有超时（规则 10）。
- **密码按字节处理。** RFC 8489 要求对密码使用 OpaqueString profile（RFC 8265）；fit 不做这一步，所以非 ASCII 的密码必须
  以该形式给出。fit 要互通的所有实现对 ASCII 密码的处理都相同。

## 需要 fib 提供的

- [A49](../fib-api-requests.zh-CN.md#a49在监听-socket-上朝某地址打开-udp-对端)：在监听 socket 上朝某个地址打开 UDP 对端，
  而该地址还没有发来任何东西。打洞要先发，且从 NAT 映射的端口发出；TURN allocation 要从中继地址向被许可的对端发送。
- [A50](../fib-api-requests.zh-CN.md#a50quic-datagram-帧)：QUIC DATAGRAM 帧，用于 UDP 流。
